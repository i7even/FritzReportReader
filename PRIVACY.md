# Privacy / Privacidade

## English

FritzReport Reader opens and analyses only files explicitly selected by the user, on the local computer. It creates no account, contains no telemetry or updater, and does not automatically transmit the report contents, name, path, hash or results.

The only external navigation exposed by the application is the support button. After an explicit click, it asks Windows to open this fixed page in the default browser:

`https://www.paypal.com/donate/?hosted_button_id=REKGGB7F68J6W`

No report data is appended to the address. The visit is governed by the privacy policies of PayPal and the user's browser.

A Support Data file can contain highly sensitive information, including IPs, MACs, device names, phone numbers, configuration, certificates, keys and encrypted passwords. The user is responsible for protecting the file and redacting identifiers before sharing any excerpt.

## Português

O FritzReport Reader abre e analisa localmente os ficheiros que o utilizador selecionar. Não cria contas, não contém telemetria, não possui atualizador e não envia automaticamente o conteúdo, nome, caminho, hash ou resultados do relatório.

A única navegação externa disponível dentro da aplicação é o botão de apoio. Depois de um clique explícito, esse botão pede ao Windows para abrir no navegador a página fixa:

`https://www.paypal.com/donate/?hosted_button_id=REKGGB7F68J6W`

Nenhum dado do relatório é acrescentado ao endereço. A visita fica sujeita às políticas do PayPal e do navegador do utilizador.

Um Support Data pode conter dados muito sensíveis, incluindo IPs, MACs, nomes de aparelhos, números de telefone, configuração, certificados, chaves e palavras-passe cifradas. O utilizador é responsável por proteger o ficheiro e por remover identificadores antes de partilhar qualquer excerto.
