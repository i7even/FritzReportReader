# FritzReport Reader v0.6.1B

## English

This is the first public beta of FritzReport Reader, a portable Windows x64 application for reading and comparing FRITZ!Box Support Data reports locally.

### Highlights

- English (UK) and Portuguese (Portugal) interface;
- interpreted event timeline with the original evidence retained;
- separate security, Internet/WAN, device/Wi-Fi, temperature, warning, error and external-port-activity views;
- temperature readings with observed minimum/maximum values kept separate from critical limits;
- organised reading of technical sections and socket tables;
- full-text search and A ↔ B report comparison;
- fully local processing with no account, telemetry, automatic upload or updater;
- portable single executable with no installer or administrator rights required.

## Português

Esta é a primeira beta pública do FritzReport Reader, uma aplicação portátil Windows x64 para ler e comparar localmente relatórios Support Data da FRITZ!Box.

- interface em English (UK) e Português (Portugal);
- cronologia de acontecimentos interpretada com a prova original preservada;
- vistas separadas para segurança, Internet/WAN, aparelhos/Wi-Fi, temperaturas, avisos, erros e atividade externa em portas;
- temperaturas com mínimo/máximo observados separados dos limites críticos;
- leitura organizada de secções técnicas e tabelas de sockets;

- executável único e portátil, sem instalador nem privilégios de administrador.
