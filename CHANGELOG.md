# Changelog

## 0.6.1B — English — 2026-08-30

- first public beta of FritzReport Reader;
- complete English (UK) and Portuguese (Portugal) interface;
- interpreted timeline with retained original evidence;
- separate warning, error and external-port-activity filters;
- observed temperatures and critical limits shown separately;
- search, A ↔ B comparison, full text and organised section reading;
- local processing with no telemetry or automatic data transfer;
- fixed PayPal support page opened only after a user click;
- fixed temperature parsing when one line contains critical minimum and maximum values;
- portable Windows x64 package with no installer.

## 0.6.1B — Português — 2026-08-30

- primeira beta pública do FritzReport Reader;
- interface completa em English (UK) e Português (Portugal);
- cronologia interpretada com prova original;
- filtros independentes para avisos, erros e atividade externa em portas;
- temperaturas observadas e limites críticos apresentados separadamente;
- pesquisa, comparação A ↔ B, texto integral e leitura organizada de secções;
- processamento local sem telemetria ou envio automático;
- botão PayPal fixo, aberto apenas por ação do utilizador;
- correção da leitura de temperaturas quando a mesma linha contém mínimo e máximo críticos;
- pacote Windows x64 portátil, sem instalador.
